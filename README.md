# 🌐 Mrutunjaya Panda – 3D Developer Portfolio

This repository contains the source code for my **3D personal portfolio website**, built using modern frontend tools to showcase my projects, skills, and experience.

🔗 **Live Website:**  
👉 https://mrutunjaya-portfolio.vercel.app/

---

## 🚀 About the Project

This portfolio is designed to provide an **interactive and visually rich experience**, featuring 3D elements along with smooth UI animations.

It highlights:
- My featured projects
- Technical skills and tools
- About & contact sections
- A modern 3D-based landing experience

---

## 🛠 Tech Stack

- **Frontend:** React.js
- **Build Tool:** Vite
- **Styling:** Tailwind CSS
- **3D Graphics:** Three.js / @react-three/fiber
- **Animations:** (if used – e.g. Framer Motion)
- **Deployment:** Vercel

# ⚙️ Installation & Setup

To run this project locally:
```
1. git clone https://github.com/Mrutunjaya-Panda/mrutunjaya-portfolio.git
2. cd mrutunjaya-portfolio
3. npm install
4. npm run dev
```
